# AI Agents

This folder contains the documentation for all AI voice agents used in the LevelUp Learning automation system.

## Available Agents

### Agent 1 – Payment Follow-up

Purpose:
Guide applicants who have submitted the application form but have not yet completed the application fee payment.

### Agent 2 – Interview Follow-up

Purpose:
Guide applicants who have completed the payment but have not yet booked their interview.

## Folder Structure

Each agent folder contains:

- Objective
- Trigger Conditions
- Conversation Flow
- Objection Handling
- Escalation Rules
- Example Conversations

The information in this folder defines the behaviour of each AI agent.
