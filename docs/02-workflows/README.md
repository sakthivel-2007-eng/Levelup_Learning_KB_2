# Workflows

This folder contains the business workflows used by the LevelUp Learning AI automation system.

The workflows define how external systems such as Tally Forms, Razorpay, Calendly, and the CRM interact with the AI agents.

## Workflow Documents

1. Event Flow – Agent 1
2. Event Flow – Agent 2
3. Trigger Timing
4. Retry Logic
5. Webhook Payload
6. Call Behaviour

## Purpose

These documents describe:

- Agent trigger conditions
- Business workflow
- External integrations
- Retry behaviour
- Call scheduling
- Required webhook fields

These workflows are used together with the AI agent prompts and course knowledge base.
