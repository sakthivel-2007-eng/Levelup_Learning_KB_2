# Deployment Guide

## Purpose

This document explains how to deploy the LevelUp Learning AI platform.

## Deployment Components

- GitHub Repository
- Knowledge Base
- Bolna AI Agent
- 2Care Backend
- Tally Forms
- Razorpay
- Calendly
- CRM

## Deployment Checklist

- Verify GitHub repository is up to date.
- Verify knowledge base documents are complete.
- Configure AI prompts.
- Connect webhook endpoints.
- Test payment workflow.
- Test interview workflow.
- Verify CRM synchronization.
- Perform end-to-end testing before production.

## Production Verification

Before going live:

- Confirm all integrations are working.
- Verify outbound AI calls.
- Validate webhook responses.
- Confirm logging and monitoring are enabled.
