# AI Prompts

This folder contains the prompts used by the LevelUp Learning AI voice agents.

These prompts define how the AI should retrieve knowledge, respond to users, handle objections, escalate conversations, and maintain a consistent conversational style.

8. Guardrails

## Purpose

The prompts ensure that every AI interaction is:

- Accurate
- Consistent
- Professional
- Context-aware
- Based only on the approved knowledge base

## AI Guidelines

- Always retrieve information from the knowledge base before answering.
- Never invent course information.
- Escalate when the required information is unavailable.
- Maintain a friendly, respectful, and professional tone.
